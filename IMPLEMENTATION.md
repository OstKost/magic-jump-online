# План доработок

## Выполнено, требуется визуальная проверка
- Призраки: управление после смерти, 80% очков, уровень до конца таймера.
- Бонусы под верхними препятствиями; стрелки на первом уровне.
- Увеличенные имена, жизни и очки.
- Одиночный режим и локальный режим на двоих.
- Независимые маршруты с одинаковыми наборами действий, бонусов и временными слотами.

## Следующие этапы
1. Проверить мобильный интерфейс и заменить временные верхние конструкции тематическими препятствиями.
2. Добавить Go-сервер и SQLite: серверный расчёт правил, комнаты на 2–4 игроков, короткие коды, WebSocket, восстановление связи за 30 секунд.
3. Подключить онлайн-интерфейс: QR/ссылки, лобби, готовность, собственная дорожка снизу и соперники сверху.
4. Добавить проверку журналов локальных игр, ввод имени победителями и общий рейтинг всех режимов. Неделя начинается в понедельник в 00:00 Europe/Moscow.
5. Развернуть на M0 (176.53.174.118), домен jump.ost.wang: HTTPS, WebSocket, постоянный том SQLite, резервное копирование и health endpoint.
6. Настроить CI/CD в конце работ: на pull request выполнять npm ci, npm test, npm run build, go test -race ./..., go vet ./... и браузерные smoke-проверки. После успешных проверок основной ветки собирать неизменяемый Docker-образ с тегом commit SHA и развёртывать на M0. SSH-ключ и проверенный host key хранить в secrets CI; продакшен-деплои сериализовать. Перед миграциями создавать резервную копию SQLite, после обновления проверять HTTPS health endpoint и WebSocket. При неуспехе возвращать предыдущий образ; несовместимые миграции не откатывать автоматически. Не перезаписывать том данных. Документировать первичную настройку секретов, восстановление и ручной откат.
