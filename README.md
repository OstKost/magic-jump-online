# Волшебный Прыжок Онлайн

Браузерная игра на TypeScript и Phaser 3 с Go-сервером и SQLite. Три мира по 60 секунд, четыре героя и их питомцы. Продакшен: https://jump.ost.wang.

## Режимы

- **1 игрок:** одна дорожка, присед под левой рукой и прыжок под правой. Клавиши W/↑ и S/↓.
- **2 игрока:** две дорожки на одном устройстве, управление слева W/S и справа ↑/↓. Каждый отдельно выбирает героя и подтверждает готовность.
- **Онлайн:** 2–4 участника на разных устройствах. Создатель приглашает друзей четырёхзначным кодом, ссылкой или QR. Все выбирают разных героев и подтверждают готовность перед каждым уровнем; создатель запускает его. Собственная дорожка расположена снизу, соперники — сверху.

У каждого свой маршрут с одинаковым числом прыжков, приседов, бонусов и временными интервалами. Успешное препятствие приносит 10 очков, бонус — 25. Наземные препятствия нужно перепрыгивать, под арками приседать. Бонусы под арками собираются в приседе; верхние — в прыжке. Стрелки-подсказки показываются только на первом уровне.

После потери трёх жизней герой становится призраком и продолжает управляться: успешное препятствие даёт 8 очков, бонус — 20. Столкновение отменяет награду за препятствие. Уровень продолжается до конца таймера, даже если все стали призраками. Следующий уровень восстанавливает жизни, сохраняя очки.

## Рейтинг и связь

После трёх уровней победители по сумме очков могут ввести имя в общий рейтинг; при ничьей сохраняется каждый победитель. Одиночный режим сохраняет итог игрока. Неделя начинается в понедельник в 00:00 по Москве; прошлые результаты остаются в базе.

Для рейтинговой локальной игры сервер выдаёт seed перед началом путешествия и проверяет журнал действий после завершения. Автономная игра доступна без записи в общий рейтинг. Аккаунты не нужны; одинаковые имена допустимы.

В локальных режимах Escape, потеря фокуса и поворот телефона ставят матч на паузу. Онлайн-матч продолжается: после потери связи можно вернуться в течение 30 секунд, в том числе перезагрузив страницу. После этого игрок выбывает из соревнования. Незавершённые комнаты и попытки хранятся в памяти и заканчиваются при перезапуске сервера; завершённые результаты сохраняются в SQLite.

## Разработка и проверка

```sh
npm ci
npm run dev
```

В другом терминале:

```sh
cd server
go run .
```

Vite проксирует `/api` и WebSocket на порт 8080. Для игры с телефона в той же Wi-Fi сети откройте Network-адрес Vite. Без Go-сервера доступны автономные локальные режимы.

```sh
npm test
npm run build
cd server
go test -race ./...
go vet ./...
```

Браузерные проверки требуют Python Playwright и Chromium:

```sh
pip install playwright
playwright install chromium
JOURNEY_QA_URL=http://localhost:5173 python scripts/qa_modes.py
```

Скрипт проверяет одиночный режим, призрака, локальную готовность на двоих, комнату на четверых, переподключение и рейтинг. Скриншоты сохраняются в `artifacts/qa/`. Общий контрольный сценарий TypeScript/Go: `node --experimental-strip-types scripts/generate-rules-fixture.ts`; менять fixture следует только при намеренном изменении правил.

## Устройство

- `src/main.ts`: локальная Phaser-сцена, ввод, экраны, журнал действий.
- `src/network.ts`: комнаты, QR, онлайн-дорожки, рейтинг и ввод имени.
- `src/rules.ts`, `src/journey.ts`: правила, маршруты, выбор и готовность.
- `server/`: авторитетный онлайн-расчёт, проверка локальных прохождений, WebSocket, SQLite.
- `public/`: атласы героев, питомцы, оформление, manifest и service worker.
- `deploy/`, `.github/workflows/ci.yml`: Docker, HTTPS, резервное копирование и CI/CD.

Установка как PWA и автономное открытие требуют HTTPS либо localhost. Ресурсы кэшируются после первого открытия; API не кэшируется. Звук и вибрация сохраняются на устройстве. Документация ресурсов: [ASSETS.md](public/assets/ASSETS.md). Инструкции эксплуатации: [deploy/README.md](deploy/README.md).
