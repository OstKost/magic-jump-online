# Волшебный Прыжок Онлайн

Локальная браузерная игра для двух игроков с выбором двух героев из четырёх: София, Стелла, Воздух и Земля. TypeScript, Phaser 3, Vite.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес из терминала. Для телефона в той же Wi-Fi сети используйте Network-адрес компьютера. Сервер разработки слушает все интерфейсы.

```sh
npm test
npm run build
npm run preview
```

Готовая статическая сборка находится в `dist/`.

## Правила

Заставка «Нажмите любую кнопку» открывает меню клавишей или касанием. «Новая игра» запускает последовательный выбор персонажа для игрока 1 и игрока 2. Один персонаж не может быть выбран обоими игроками. У каждого героя свой кот, портрет и игровые анимации.

Путешествие всегда начинается с первого уровня. Перед каждым уровнем персонажи и коты ждут в анимации покоя, таймер и препятствия стоят. Каждый игрок отдельно нажимает «Я готов», свою экранную кнопку или клавишу: W/S для игрока 1, ↑/↓ для игрока 2. Повторное нажатие первого игрока не заменяет готовность второго. После готовности обоих начинается бег.

Три мира по 60 секунд. Каждый новый уровень восстанавливает три жизни и сохраняет очки. Препятствие: +10, предмет: +25. Если до конца уровня дожил хотя бы один игрок, команда побеждает; если оба потеряли все жизни, появляется экран поражения. Повторная попытка перезапускает текущий уровень и отменяет очки неудачной попытки. После победы доступен следующий уровень, после третьего — новое путешествие с выбором персонажей. Выбора уровня нет.

Escape и кнопка паузы останавливают игру. Из паузы можно продолжить или вернуться в меню; «Продолжить» сохраняет текущий матч и выбор героев. Скрытие вкладки и потеря фокуса также ставят игру на паузу.

## Устройство проекта

- `src/rules.ts`: правила, конфигурации миров, воспроизводимая последовательность объектов.
- `src/main.ts`: Phaser-сцена, дорожки, ввод и экраны игры.
- `src/characters.ts`: четыре героя, портреты, питомцы и параметры анимаций.
- `src/journey.ts`: последовательность выбора и независимая готовность двух игроков.
- `src/style.css`: адаптивное оформление.
- `public/assets/`: PNG-кадры и атласы героинь, фон, препятствия и анимированные PNG котиков.

Активные персонажи используют очищенные `atlas-clean` с восемью сгенерированными фазами бега по референсу `pics/sprite.png`. Подключены бег, прыжок и падение, рисованный фон и препятствия. Полная карта ресурсов, точки привязки и ограничения исходника: [public/assets/ASSETS.md](public/assets/ASSETS.md).

Игра не требует сервера приложения, аккаунтов или сохранения данных. После обновления страницы матч начинается заново. Шрифты загружаются из Google Fonts, при отсутствии сети используются системные.

## Мобильный интерфейс

Полноэкранный интерфейс: заставка, главное меню, выбор героев, ожидание готовности, игра, результаты и настройки. Меню и карточки используют исходные концепты из `pics/`, скопированные в `public/art/`. Героини загружаются из подготовленных атласов. Игровой экран следует схеме `pics/blueprint_design.heic`: горизонтальное положение телефона, две дорожки в центре, полноразмерная кнопка прыжка Софии слева и Стеллы справа. Поддерживаются одновременные касания. В вертикальном положении появляется подсказка поворота и матч приостанавливается; после поворота продолжается, если пауза была вызвана ориентацией. Размер поля пересчитывается без сброса очков, препятствий и положения героинь. При уходе с экрана приложение ставит игру на паузу; кнопка «Продолжить» возвращает текущий матч. Настройки звука и вибрации сохраняются локально.

Добавлены web manifest и service worker для установки как PWA. Установка и автономное открытие требуют HTTPS (либо localhost); ресурсы игры кэшируются после первого открытия. Это мобильное веб-приложение, сборка для App Store / Google Play не создаётся.

## Прыжок и присед

Игрок 1: W — прыжок, удерживать S — присед. Игрок 2: ↑ — прыжок, удерживать ↓ — присед. Управление зависит от стороны игрока, а не от выбранного героя. На экране кнопки каждого игрока разделены: прыжок сверху, присед снизу. Под верхним бревном с меткой «↓ ПРИСЕД» нужно пригнуться; наземные камни, частокол и брёвна нужно перепрыгивать. За успешное уклонение начисляется +10. Отпускание кнопки возвращает бег; во время приседа прыжок заблокирован. Пауза сбрасывает присед.

Все движения Софии и Стеллы используют PNG-атласы из `public/assets/characters/`, описанные в [ASSETS.md](public/assets/ASSETS.md).

## Питомцы

У каждого персонажа свой спутник:
- У Софии — чёрный котёнок Черныш с голубым платком.
- У Стеллы — рыжий котёнок Рыжик с красным платком.
- У Янга (Воздух) — орёл.
- У Болдера (Земля) — лиса.

Котята анимированы в 4 фазы бега, орёл и лиса используют полноцветные рисованные спрайты с динамическим покачиванием и реакцией на прыжки героя. Питомцы плавно меняют дистанцию, догоняют и подпрыгивают вслед за персонажами. Ресурсы описаны в [pets/README.md](public/assets/pets/README.md).

Фон движется с параллаксом: земля прокручивается со скоростью препятствий, дальние слои — медленнее. На паузе прокрутка останавливается. Исходники новых анимаций и точные запросы генерации сохранены в `public/assets/characters/generated/`.

## Экраны и проверка сценария

Экраны победы и поражения: `public/art/victory.png`, `public/art/defeat.png`. Питомцы персонажей: `public/assets/pets/eagle.png` (Янг, Воздух), `public/assets/pets/fox.png` (Болдер, Земля). Иллюстрации согласованы со стилем концептов и подготовлены на прозрачном фоне. Питомцы выбранной пары отображаются в меню, выборе, игре и результатах; на первой заставке — коты Софии и Стеллы.

`npm test` проверяет правила, выбор героев и готовность. Для сквозной браузерной проверки запустите Vite и `JOURNEY_QA_URL=http://localhost:5173 python scripts/qa_journey.py` (нужны Python Playwright и Google Chrome). Скрипт проверяет клавиатуру и экранные кнопки, ожидание второго игрока, питомцев, паузу, победу, поражение, повтор, следующий уровень и финал. Кадры проверки сохраняются в `artifacts/qa/`.

## Режимы и онлайн

Меню предлагает одного игрока, локальную игру на двоих и онлайн-комнаты на 2–4 участников. Одиночные кнопки расположены снизу: присед слева, прыжок справа. В онлайне собственная дорожка большая снизу, соперники — сверху. Код комнаты состоит из четырёх цифр; QR и ссылка ведут на страницу входа с уже заполненным кодом. Все участники выбирают разных героев и подтверждают готовность; создатель запускает уровень.

Каждый участник получает свою перестановку препятствий и бонусов с одинаковым количеством действий и временными интервалами. После потери жизней игра продолжается в виде призрака: 8 очков за успешное препятствие, 20 за бонус. Столкновения не дают награды. Бонусы под арками собираются в приседе. Стрелки-подсказки появляются только на первом уровне.

После трёх миров победители по сумме очков вводят имя в общий недельный рейтинг. Для локальных рейтинговых попыток требуется интернет при начале и отправке итога; сервер проверяет журнал действий. Автономная игра остаётся доступна без записи в общий рейтинг. Новая неделя начинается в понедельник в 00:00 по Москве.

Сервер: `cd server && go run .`. Клиент: `npm run dev`. Тесты: `npm test`, `npm run build`, `cd server && go test -race ./... && go vet ./...`. Браузерная проверка новых режимов: `python scripts/qa_modes.py` (Python Playwright и Chromium).

Развёртывание, CI/CD и резервное копирование: [deploy/README.md](deploy/README.md). Старые разделы выше описывают исходную версию игры; актуальные режимы и правила приведены в этом разделе.
