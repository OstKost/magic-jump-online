# Состояние задач для продолжения

Снимок: 30 октября 2026. Этот файл фиксирует состояние основной сессии; при продолжении сначала сверить Git и GitHub Actions, поскольку параллельная работа продолжается.

## Цель и принятые решения

Реализовать все пункты плана в IMPLEMENTATION.md и закончить настройку CI/CD.

- Режимы: один игрок, два на одном устройстве, онлайн на 2–4 устройствах.
- Онлайн: четырёхзначный цифровой код с ведущими нулями, ссылка и QR; запуск создателем после готовности всех.
- Свой воспроизводимый маршрут каждому, одинаковые возможности набрать очки и безопасные интервалы.
- **Последнее уточнение пользователя:** призрак нужен для продолжения игры рядом с живыми участниками. Когда умирают все, попытка уровня заканчивается поражением. В одиночном режиме смерть завершает попытку сразу. Повтор отменяет очки неудачной попытки.
- Призрак получает 80% целыми числами: 8 за препятствие и 20 за бонус. Столкновение отменяет награду за препятствие.
- Победители определяются после трёх уровней по сумме очков; при ничьей имя вводит каждый победитель. Рейтинг общий для всех режимов, неделя начинается в понедельник в 00:00 по Москве.
- Сервер Go, SQLite. M0: 176.53.174.118, домен https://jump.ost.wang.
- Онлайн не останавливается при потере фокуса/связи; окно возвращения 30 секунд, затем участник выбывает.
