# Игроки 3 и 4 — Воздух и Земля

Исходник: `pics/ sprite-2.png`, 1774 × 887 пикселей. **В имени исходного файла есть начальный пробел.** Оригинал сохранён без изменений. Все пути ниже относительно `public/assets/`, браузерные URL начинаются с `/assets/`.

## Персонажи

- Игрок 3 — **Янг** (стихия Воздух, питомец — орёл), папка `characters/air/`: светлый костюм, бирюзовый шарф, воздушные шлейфы.
- Игрок 4 — **Болдер** (стихия Земля, питомец — лиса), папка `characters/earth/`: зелёно-коричневый костюм, камни и земляные эффекты.

Технические ключи в коде — `air` и `earth`.

В каждой папке 19 игровых кадров с одинаковыми именами:

- `run-00.png` … `run-05.png` — 6 фаз бега слева направо. Рекомендуется цикл 10 кадров/с.
- `jump-00.png` … `jump-04.png` — 5 фаз: подготовка, отталкивание, верхняя точка, снижение, приземление. Проигрывать однократно либо выбирать по фазе физического прыжка; ориентир — 6 кадров/с.
- `idle-00.png` … `idle-02.png` — 3 варианта ожидания. Можно использовать первый как статичный кадр; для смены вариантов ориентир — 3 кадра/с. Это разные позы из концепта, плавность цикла не гарантируется.
- `duck-00.png`, `duck-01.png` — приседание и низкая вытянутая поза, 8 кадров/с однократно. На второй позе исходник содержит комические эффекты столкновения — облачко у Воздуха, камни у Земли; они сохранены.
- `hit-00.png` … `hit-02.png` — 3 фазы падения/столкновения, 5 кадров/с однократно.

Каждый игровой кадр — прозрачный RGBA PNG **256 × 256**. Рисунок не увеличен и не перерисован; центрирован по горизонтали, нижняя видимая точка находится на y=240. Точка привязки: **`setOrigin(0.5, 240/256)`**. Внешние эффекты входят в границы рисунка; это не границы коллайдера. Из-за шлейфов/камней для идеального совпадения положения тела могут потребоваться индивидуальные поправки кадров. На втором листе персонажи мельче, чем на первом: одинаковый холст не означает одинаковую высоту тела при одинаковом масштабе отображения.

## Атласы

В каждой папке находятся:

- `atlas.png` — 1792 × 768, 7 столбцов × 3 строки, 19 занятых ячеек и 2 пустые.
- `atlas.json` — Phaser JSON Hash; имена кадров без `.png`, например `run-00`.

Порядок ячеек: run → jump → idle → duck → hit. Частоты, списки кадров, исходные прямоугольники и номера игроков записаны в `sprites-3-4.json`.

```ts
this.load.atlas('air', 'assets/characters/air/atlas.png', 'assets/characters/air/atlas.json');
this.load.atlas('earth', 'assets/characters/earth/atlas.png', 'assets/characters/earth/atlas.json');
this.anims.create({
  key: 'air-run',
  frames: Array.from({ length: 6 }, (_, i) => ({
    key: 'air', frame: `run-${String(i).padStart(2, '0')}`,
  })),
  frameRate: 10,
  repeat: -1,
});
this.add.sprite(160, floor, 'air', 'idle-00')
  .setOrigin(0.5, 240 / 256).play('air-run');
```

## Портреты и вид со спины

Это отдельные прозрачные PNG, обрезанные по видимому рисунку, с переменными размерами; в игровые атласы не входят.

- `characters/air/portrait-00.png` … `portrait-03.png` — спокойное выражение, улыбка, смех с закрытыми глазами, удивление.
- `characters/earth/portrait-00.png` … `portrait-04.png` — спокойное выражение, улыбка с закрытыми глазами, смех, сердитое выражение, удивление.
- `characters/air/back-00.png` … `back-03.png` — четыре варианта вида со спины.
- `characters/earth/back-00.png` … `back-03.png` — четыре варианта вида со спины.

Всего 17 дополнительных изображений персонажей. Для портретов удобно использовать центр `(0.5, 0.5)`, для вида со спины — середину нижнего края `(0.5, 1)`.

## Препятствия и декорации

Прозрачные PNG **256 × 192**, точка опоры `(128,176)`: **`setOrigin(0.5, 176/192)`**. Растительность у основания сохранена.

Воздух:

- `obstacles/air/lantern.png` — каменный фонарь.
- `obstacles/air/stakes.png` — деревянный частокол.
- `obstacles/air/rocks.png` — группа скал.
- `obstacles/air/banner.png` — знамя Воздуха.

Земля:

- `obstacles/earth/rock-log.png` — камни, пень и наклонное бревно одной композицией: рисунки в исходнике соединены.
- `obstacles/earth/stakes.png` — деревянный частокол.
- `obstacles/earth/lantern.png` — каменный фонарь.
- `obstacles/earth/banner.png` — знамя Земли.

Знамёна лучше использовать как декорации, остальные объекты подходят для препятствий с отдельными логическими коллайдерами.

## Фон и состояние подключения

Для этих стихий подходит ранее подготовленный общий фон `backgrounds/jade-valley.png`: горы, водопад, каменная дорожка, сосны. Новая генерация не понадобилась. Это статичный фон 1536 × 1024; поверхность земли примерно на 82% высоты. Бесшовность для скролла не гарантируется.

Ресурсы игроков 3/4 подготовлены для подключения. Текущая игра по-прежнему рассчитана на двух игроков — Софию и Стеллу; управление, интерфейс и правила на четырёх игроков не расширялись.

## Просмотр и воспроизведение нарезки

- `sprite-preview-3-4.jpg` — обзор 38 игровых кадров на контрастном фоне.
- `sprite-extras-3-4.jpg` — обзор портретов, видов со спины и 8 препятствий.
- `sprites-3-4.json` — машиночитаемая карта ресурсов.
- `scripts/prepare_sprites_3_4.py` — воспроизводимая нарезка; запуск из корня проекта: `python scripts/prepare_sprites_3_4.py`. Зависимости: Pillow, NumPy, SciPy.

Пергамент удалён по связанным с краем светлым областям; внутренние замкнутые светлые детали сохранены. Исходник — концепт-лист: общие шлейфы и камни местами пересекают границы соседних кадров, поэтому возможны видимые обрывы эффектов. Подписи, линии разметки и крупные иллюстрации персонажей не включены в игровые кадры. Отдельные полосы эффектов внизу листа и цветовые палитры не нарезались; эффекты внутри анимационных поз сохранены.
